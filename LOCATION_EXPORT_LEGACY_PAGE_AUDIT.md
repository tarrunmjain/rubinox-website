# Location and Export Legacy Page Audit

Project: Rubinox Metal and Alloys  
Website: https://rubinoxmetal.com  
Repository: tarrunmjain/rubinox-website  
Audit phase: Phase 0 before creating location/export architecture  
Business positioning: Stockist | Supplier | Importer | Exporter | Project Supplier

## Scope

This is a documentation-only audit. It scans existing `.html` files, `sitemap.xml`, titles, H1s, canonicals, URL paths and internal HTML references for city, country, export, location, Mumbai, India and legacy local SEO signals. No website pages, sitemap entries, schema, CSS, JavaScript or images were modified.

## Key Findings

- There are currently no dedicated `/locations.html`, `/locations/<city>.html`, `/export.html` or `/export/<country>.html` pages.
- No country-specific export pages were found for UAE, Saudi Arabia, Qatar, Oman, Kuwait, Bahrain, Singapore, Malaysia, Thailand, Vietnam, USA, UK, Germany, Netherlands or Australia.
- The only explicit legacy city/local SEO page found is `materials/stainless-steel-supplier-mumbai.html`.
- The homepage and contact page include Mumbai/India positioning, but they are core pages rather than location landing pages.
- The site contains many broad India-style material and grade pages using `supplier-india` intent. These should be treated as material SEO pages, not city/export architecture pages.
- No sitemap-only orphan was found among explicit location/export candidates. The Mumbai legacy page is in the sitemap and has a low internal link count, so it should be connected into a future Mumbai cluster rather than deleted.
