## 2. Recommended Page URL

## 16. Mobile and Accessibility Notes

Mobile requirements:
- Hero should stack cleanly on mobile.
- Trust cards should collapse to one column.
- CTA buttons should become full-width or wrap cleanly.
- Avoid long unbroken phrases inside cards.
- Keep Bharat Metals heritage section readable on 360px to 430px widths.

Accessibility requirements:
- Maintain one H1.
- Use semantic `<main>`, `<section>`, and `<nav>` where appropriate.
- Use descriptive link text, not `click here`.
- CTA links must have clear accessible text.
- Images need descriptive alt text.
- Decorative icons should use `aria-hidden="true"`.
- FAQ headings should maintain logical heading order.
- Color contrast should match Rubinox navy/gold/silver standards.

Visual guardrails:
- Keep headings in `var(--ink2)` / `#132a63` where appropriate.
- Keep body text muted but readable.
- Avoid heavy overlays that make content difficult to read.

## 17. Implementation Risks

Key risks:

1. New URL requires sitemap and navigation decisions.
   - If `/about-us.html` is created, update `sitemap.xml` and consider nav/footer links.

2. Static header duplication.
   - Navigation changes may require repeated edits across many pages.

3. Bharat Metals wording must be verified.
   - Avoid legal or historical claims unless confirmed.

4. Schema mismatch risk.
   - FAQPage schema must match visible FAQs.

5. Unsupported trust claims.
   - Do not invent certifications, approvals, clients or guaranteed documentation.

6. Manufacturer confusion.
   - The About page must consistently describe Rubinox as stockist, supplier, importer, exporter and project supplier.

7. SEO cannibalization.
   - About page should support company trust, not compete too heavily with homepage for broad `stainless steel supplier in India` terms.

8. Mobile card density.
   - Premium trust cards and FAQ sections must be kept scannable on mobile.
