# Keyword Master Architecture - Batch 4

Date: 2026-06-29
Scope: planning and data architecture only. No public pages were created or edited.

## 1. Keyword Universe Overview

Batch 4 expands the Rubinox keyword database from a small starter map into a controlled starter architecture. The matrix now covers material, grade, product form, specification, city, state, export, price-factor, RFQ and AEO/GEO/LLMO-style query patterns.

## 2. Keyword Categories

Categories include material keywords, grade keywords, product form keywords, specification keywords, city keywords, state keywords, country/export keywords, price-factor keywords, RFQ keywords and answer-style informational queries.

## 3. Page-Type Mapping

Material keywords map to material family pages. Grade keywords map to grade pages. Specification keywords map to specification pages or technical resources. Product-form keywords map to product form pages. City, state, product-city and country/export keywords map to existing pages or planned future URLs.

## 4. Primary URL Rules

Every keyword has one primary URL. Future planned pages can be listed as primary URLs, but they remain planned until implementation is approved.

## 5. Secondary URL Rules

Secondary URLs support the topic through related context, quotation handoff or technical resources. They should not compete as alternate primary pages for the same exact query.

## 6. Cannibalization Prevention

Avoid assigning the same query to both a broad location page and a product-city page. Product variants should be grouped when one useful page can satisfy multiple close query variants.

## 7. Dealer Vs Supplier Wording Strategy

Dealer terms remain search-intent labels in the matrix. Public copy should use supplier, stockist, importer, exporter and project supplier language. Do not imply authorized dealership, local offices or local inventory unless verified.

## 8. India Vs City Vs State Vs Country Targeting

India-level keywords usually map to material, grade, specification, product form or quotation pages. City keywords map to city or product-city pages. State pages should be used sparingly. Country keywords should use exporter-from-India phrasing.

## 9. Product-Form Keyword Strategy

Product-form pages are strong RFQ targets for pipes, tubes, sheets, plates, coils, flanges, fittings, fasteners, angles, channels, bars, rods, wire mesh and perforated sheets. Future modules should use RFQ detail cards, grade chips and technical links.

## 10. Grade/Spec Keyword Strategy

Grade and specification keywords map to existing pages where available. New spec pages should not be created for near-duplicate wording variants.

## 11. Price-Factor Keyword Strategy

Price-factor keywords map to existing price-factor guides. These pages explain variables such as grade, size, form, quantity, documentation, testing, packing and logistics. They must not publish fixed prices, live prices or price lists.

## 12. AEO/GEO/LLMO Keyword Strategy

Answer-style keywords should map to pages that can answer visibly and concisely. Good targets include grade pages, technical resources, quality documentation support and Knowledge Hub articles. FAQ schema requires matching visible FAQ content.

## 13. Visual Implementation Without Clutter

Use compact chips, cards, FAQs, related links, RFQ checklists, technical resource callouts and city-specific buyer modules. Do not add repeated keyword blocks or hidden text.

## 14. What Not To Do

- Do not add footer keyword stuffing.
- Do not add hidden text.
- Do not publish duplicate city pages.
- Do not imply fake local offices, branches, warehouses or stockyards.
- Do not add fake inventory, fixed price lists, fake certifications, fake clients, fake projects, fake reviews or fake ratings.
- Do not create doorway pages.

## 15. Future Search Console Review Process

After Search Console access is available, review impressions, clicks, CTR and query/page matches monthly. Promote only keyword groups with proven impressions, real buyer value and safe implementation paths.
