# D11C - Mega SEO/GEO/AEO Page Expansion

## Summary

D11C creates a one-time controlled SEO/GEO/AEO expansion for Rubinox Metal and Alloys using material, grade, form and destination search intent. The batch creates 240 content pages plus 3 discovery hub pages.

The final sitewide design system is preserved: top bar, header, final shared CSS, unified footer, six tiled footer icons, card accent system, individual FAQ cards and gold CTA buttons.

## Internal Link Strategy

- No new footer bulk links were added.
- No main navigation bloat was added.
- Discovery is routed through three controlled hubs.
- Existing pages updated with a compact D11C hub-discovery card: `materials.html`, `product-forms.html`, `locations.html`, `export.html`, and `quotation.html`.
- New pages link to relevant existing material, grade, form, city/export, documentation, technical resource, quotation and contact pages where those URLs already exist.

## Schema Summary

Each new content page and hub includes valid JSON-LD for WebPage, BreadcrumbList, Organization reference and FAQPage. No Offer, Review, Rating, fixed-rate or fake commercial schema was added.

## Safety Rules Followed

- Rubinox positioning remains stockist, supplier, importer, exporter and project supplier.
- No unsupported business-role wording was added.
- No certification, approval, client, project, review, rating, award, fixed commercial, inventory or time-bound commitment wording was added.
- Existing public URLs, title/meta/canonical/schema meaning and GA4 configuration were preserved.
- CNAME/custom domain was not changed.
