# Owner Data Needed For Trust Assets

Date: 2026-06-29

These items should not be invented or published without owner verification and approval.

- GST number and approval for public display.
- MSME/Udyam details and approval for public display.
- IEC details and approval for public display.
- Certificate images or document scans.
- Real office photos.
- Real stock or catalogue photos.
- Approved team/contact person photo, name and designation.
- Real client names, only if approved.
- Real project references, only if approved.
- GA4 measurement ID confirmation beyond the current site implementation.
- Google Search Console verification method.
- Bing Webmaster verification.
- Google Business Profile review link.
- LinkedIn, Facebook and Instagram official links if any change or are missing.
- Company profile PDF approval before sending externally.
- Business hours before adding any team-online timing.
