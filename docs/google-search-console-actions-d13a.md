# Google Search Console Actions - D13A

## Purpose

Prepare the frozen Rubinox website for controlled Google indexing monitoring. Codex has not performed any authenticated Search Console submission or URL inspection. The owner must complete these steps manually inside the existing Rubinox property.

## Sitemap Steps

1. Open the existing Rubinox Search Console property.
2. Go to Sitemaps.
3. Confirm or submit: sitemap.xml
4. Full URL: https://rubinoxmetal.com/sitemap.xml
5. Record submission date, sitemap status, discovered URL count, last read date, errors and warnings.
6. Do not submit the same sitemap repeatedly every day.

For each inspected URL record:

- URL is on Google / not on Google.
- Crawl allowed.
- Page fetch successful.
- User-declared canonical.
- Google-selected canonical.
- Last crawl date.
- Indexing issue, if any.
- Request indexing action if appropriate.

Requesting indexing does not guarantee indexing or ranking. All 634 URLs should be discovered mainly through the sitemap and internal links, not manual bulk submission.
